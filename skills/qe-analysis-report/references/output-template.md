# 报告模板

中文为主，术语保留英文原名（PBE、DFT-D3、E_ads），避免中英混杂长句。篇幅默认 8–15 页。

## 模式 A：单体系深度分析

适用：一个吸附体系 + 收敛性测试。

1. **摘要**：一句话背景 → 做了什么 → 主要结论（数值+单位）→ 数据状态（参考能量是否补齐）。
2. **体系与计算设置**：材料（手性、修饰、分子、位点）、泛函/赝势/截断能/k 点/展宽/自旋/色散校正/收敛阈值；参数与 pwi 一致，逐项列出。
3. **数据质量说明**：JOB DONE、SCF 收敛、重复/缺失文件、CSV 状态。
4. **收敛性验证**：ecutwfc、k 点对总能的收敛趋势；说明所选参数相对收敛值的能量差；未收敛项如实标注。
5. **结果与讨论**：
   - 吸附能（有参考能量：绝对值表+符号约定；无参考能量：组内相对稳定性+待补模板）；
   - 结构参数：吸附距离、关键键长变化、结构畸变、稳定吸附位判定；
   - 与同类体系/文献趋势对照（仅作趋势佐证，标注来源）。
   **每张表/图后必须跟分析段落**（见 analysis-standards/reasoning.md 四步法），禁止纯罗列。
6. **结论**：编号化，每条=结果+依据。
7. **附录**：完整数据表（能量、力、结构参数、提取日志）。

### 可选节：仿真-实验互证（仅当提供实验数据时）

在"结果与讨论"后增加一节：① 声明响应口径与实验条件（浓度/温度/背景气）→ ② 与仿真排序对照（排序对照表）或机理对照（用 DFT 指标解释实验机制）→ ③ 跨文献/跨数据源对齐表（逐列对齐后比较）。无实验数据时在"数据说明"写明"未提供实验数据"，不写互证结论。

## 模式 B：批量体系对比

适用：一组同源体系（如同一手性×多修饰×多分子×多位点，或 94 体系全集）。

1. **摘要**。
2. **数据集与方法**：体系构成（数量、维度：修饰×分子×位点×手性）、分组方式、计算设置。
3. **数据质量与覆盖率**：完成体系数、缺失/未收敛/重复清单（表）。
4. **收敛性验证**（有 convergence_test 时）。
5. **结果与讨论**：
   - 维度一：位点比较（同组内 top/bridge/hollow 相对稳定性排序）；
   - 维度二：分子比较（同修饰下手性/位点一致时的相对强弱排序；有参考能量时给绝对值）；
   - 维度三：修饰比较（pure/Pt/PtN/PtPd 对吸附强弱的影响）；
   - 异常体系排查（能量/结构偏离整体趋势者，逐例说明原因假设，标注为推测）。
   **每个维度小节都必须以"排序/量级/归因/综合"的推理链收尾**，不允许只给表格。
6. **结论**：按维度归纳，编号化。
7. **附录**：全量数据表。

### 可选节：仿真-实验互证（同模式 A）

## 待补参考能量模板（无 E_ads 时用）

```markdown
> 吸附能 E_ads = E(复合物) − E(基底) − E(气体)，本报告暂未提供参考能量，
> 无法给出绝对值。所需参考能量清单：裸基底 8 个（4 修饰 × 2 手性）、
> 孤立分子 5 个（H₂S/SO₂/SOF₂/SO₂F₂/SF₆），均按与复合物相同参数计算。
> 补齐后本报告可直接生成 E_ads 绝对值表与跨体系排序。
```

## 图表规划

- 收敛性：总能量 vs ecutwfc / k 点（折线或柱状）；
- 吸附能：同组位点柱状图；批量模式另加修饰×分子热力图；
- 结构：稳定吸附位示意图（如有结构可视化数据）；
- 所有图由脚本从解析数据绘制，缺数据自动跳过。

## 图文结合（图不集中堆在文末）

- **先引后述，图随文走**：正文在首次讨论某图的段落后放置图锚点 `<!-- FIG:<图文件名不含扩展名> -->`，渲染时图片与图注插入该锚点位置；
- 每张图必须有对应的论述段落（排序/量级/归因），没有就不放锚点、不硬凑图；
- 图注由绘图脚本生成（含数据来源与单位口径），正文引用用"图 X 显示……"；
- 在 writing_flow 内可用的图锚点：`qe_fig1_site_map`（位点热力图）、`qe_fig2_site_flip`（位点翻转）、`qe_fig3_outlier`（异常构型）、`qe_fig4_convergence`（收敛性）。

## 分析素材（脚本产出，正文必须消化）

`build_report.py` 会在报告中附带"分析素材"（位点排序与 ΔE、组内异常提示、收敛性相邻参数差值）。正文不得照抄素材列表，必须把其中关键数值组织成四步法分析段落；素材中有"异常/待确认"标记的体系，正文必须回应（核对建议或降级结论）。
