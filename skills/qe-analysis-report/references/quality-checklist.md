# 报告质量门

交付前逐项核查（对齐写作 crew 的七项核查：溯源/一致性/外推/单位/红线/物理严谨/结构范式）。

## 溯源
- [ ] 每个数值可追溯到具体文件（pwi/pwo/CSV）与提取位置；
- [ ] 无编造数值、无文献默认值冒充计算值；引用文献趋势时标注来源与"仅供参考"。

## 一致性
- [ ] 同一物理量全文符号、单位、正负约定一致（E_ads 负号=放热需在首次出现处定义）；
- [ ] 表中数值与正文叙述一致，图表数据与解析输出一致；
- [ ] 精度一致：不出现一处 2 位小数、另一处 4 位小数的同类量。

## 外推与物理严谨
- [ ] 组内相对比较只用于化学组成相同的体系；
- [ ] 未算过渡态不下脱附/恢复结论；未算声子注明 0 K 静态值；
- [ ] 吸附类型（化学/物理）判定给出依据（能量+距离），不凭感觉；
- [ ] 异常体系解释标注为推测，不写成定论。
- [ ] 最大力判据考虑 selective dynamics 冻结原子影响（pwo 力块含冻结原子），不单凭 max_force 判定弛豫失败。

## 单位与数值纪律
- [ ] 单位齐全：能量 eV（或 Ry 并给换算）、距离 Å/nm、电荷 e；
- [ ] 换算正确：1 Ry = 13.6057 eV；1 Ry/a.u. = 25.711 eV/Å；
- [ ] 保留有效位数，不四舍五入成整数；
- [ ] 电荷转移量单位是 e，不是 eV。

## 红线
- [ ] 无 E_ads 参考能量时没有出现绝对值吸附能；
- [ ] 未计算的量（带隙、功函数、电荷转移等）未出现在结论中；
- [ ] 未收敛/缺失/重复文件被如实报告而非忽略。

## 结构范式
- [ ] 章节完整（摘要→方法→数据质量→收敛性→结果→结论→附录）；
- [ ] 摘要与结论编号化、有据可依；
- [ ] 表格先引后述、图注自包含、中文图题/表题。

## 逻辑分析（重点）
- [ ] 每个结果小节含至少两个分析动作（排序、量级判断、趋势、关联、异常、组间对比、归因之一），不存在"表后无分析"段落；
- [ ] 每个关键结论有从数值到结论的显式链条：引用数值 → 比较/量化 → 归因 → 综合；
- [ ] 差异给出量级判断（meV vs eV、与室温 kT≈25 meV 比较、每原子数值）；
- [ ] 异常体系被识别并回应（核对建议或降级结论），未直接忽略；
- [ ] 综合结论说明依据了哪些维度，不确定处标注"待确认/推测"。

## 比较协议（排序/选择性/互证）
- [ ] 每个排序/对比前声明了比较口径（同一指标、同一条件、单位/符号一致），跨条件只比趋势；
- [ ] 报告声明了每个 DFT 指标对应的实验观测量；指标排序不一致时说明了主导指标选择依据；
- [ ] 跨维度比较遵守变量隔离（一次只变一个变量，或回到共同子集）；
- [ ] 提供实验数据时完成互证（排序对照或机理对照）并注明口径；无实验数据时明确说明，未写"与实验一致"。
