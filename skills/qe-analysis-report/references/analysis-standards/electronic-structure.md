# 电子结构分析规范：从吸附到响应的解释链

## 解释链（写作必须按链组织；缺环处明确标注"未提供数据"）

**E_b（吸附热力学）→ Q_T（电子转移量）→ ΔE₁/ΔE₂（前线轨道能差，电子转移难易）→ Eg/能带（导电性变化）→ DOS/PDOS、DCD（轨道杂化与电荷空间分布）→ 宏观灵敏度/响应**

来源：用户蒸馏页《电子结构指标构成从吸附到响应的完整解释链》；博士论文 5.4.3；W4399297249 3.3。

## 各环判读规则

- **ΔE₁/ΔE₂**：ΔE₁ = 载体HOMO − 分子LUMO，ΔE₂ = 载体LUMO − 分子HOMO；差值越小，电子越易转移、吸附越强（来源：博士论文 表5.3；换算 1 ha = 27.2114 eV）。
- **能隙 Eg**：吸附后能隙减小 → 电子转移能力提高 → 宏观电阻变化率高；增大 → 响应不灵敏；不变 → 无增益（来源：博士论文 表5.4）。**口径警告**：HOMO-LUMO 是分子轨道口径，与严格周期带结构不等价，跨文献比较须注明。
- **DOS/PDOS**：吸附前后总态密度/分波态密度对比，观察轨道杂化与杂质态（来源：W4399297249 Fig. S2–S5；博士论文 5.4.3）。
- **DCD（差分电荷密度）**：给出转移电子量（单位 e）、转移方向、电荷集中区域，回答"电荷在哪些原子间转移"（来源：W4399297249 Fig. 7）。

## 多指标互证要求

- 至少 2–3 个指标交叉验证；**单指标（尤其只有吸附能）不足以支撑"灵敏度最高"结论**；
- 引用结论时明确所依据的是解释链中的哪一环（来源：用户蒸馏页《电子结构指标…》发现 5）。

## 启用条件与红线

- 数据包含能带/DOS/DCD/电荷密度等后处理文件时启用；当前 QE 归档不含这些文件，报告应把整条链标注为"数据未提供，待补充"，不得写电子结构结论；
- 没有对应数据文件，不得写带隙、功函数、电荷转移、DOS 结论。
