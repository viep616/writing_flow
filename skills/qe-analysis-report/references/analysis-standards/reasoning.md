# 从数据到结论的推理规范（核心）

报告的"结果与讨论"必须由**分析段落**构成，禁止"表格 + 一句话"式的数据罗列。每张表/每张图之后，至少完成一次完整的"四步法"推理。

## 四步法

1. **观察（引用数值）**：指出具体数字与单位，不转述表格全部内容，只挑关键值。
2. **比较（量化差异）**：给出排序、差值（meV/eV）、倍数或趋势；差异要有量级判断（"同数量级""差两个数量级""小于室温热涨落 kT≈25 meV"）。
3. **归因（解释原因）**：用结构/电子结构/数据质量解释差异来源；无把握时给出候选假设并标注为推测。
4. **综合（收束结论）**：把本节的观察连成一条推理链，给出带依据的结论；多证据时说明综合了哪些维度。

## 常用分析动作（每次至少完成两个）

- **排序**：E_A < E_B < E_C，给出具体数值差；
- **同条件比较**：排序前声明口径（同一指标、同一条件、单位/符号一致），跨条件只比趋势；
- **变量隔离**：归因前确认只改变一个变量（修饰/配比/位点/分子/手性之一），跨维度比较回到共同子集；
- **指标映射**：声明每个 DFT 指标支撑的结论类型（吸附能→吸附难易，电荷转移→电学响应，距离→耦合），不一致时说明主导指标选择依据；
- **量级判断**：差异在 meV（近简并）还是 eV（显著）量级；与室温 kT（≈25 meV）比较；
- **趋势**：随某变量（截断能、k 点、修饰、分子、位点）单调/非单调变化；
- **关联**：两列数据是否相关（如吸附能越负是否伴随电荷转移越大），指出正/负相关；
- **异常识别**：同组内偏离整体趋势或数值可疑（如完全相同的能量、> 500 meV 的跳变），给出核对建议；
- **组间对比**：位点 → 分子 → 修饰 → 手性逐层推进；
- **机理归因**：用键合、电荷转移、结构参数、数据质量解释观察（来源：博士论文 p91 对 -OH 增强吸附的归因）。

排序/选择性/对比类结论还须满足 [comparison-protocol.md](comparison-protocol.md) 的比较协议；仿真与实验数据同时存在时启用 [simulation-experiment-verification.md](simulation-experiment-verification.md)。

## 反模式（禁止）

- "表 1 显示 A=−1.2、B=−1.5、C=−1.8 eV" 后无任何分析；
- "可以看出 X 更稳定" 但不给差值、不给量级、不给原因；
- 只有结论（"该体系吸附能力强"）而没有从数值到结论的链条；
- 把表格复制进正文当分析；
- 异常值直接删除或忽略，不说明。
