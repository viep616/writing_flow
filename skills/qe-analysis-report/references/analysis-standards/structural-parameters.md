# 结构参数分析规范

## 必报参数

- 吸附距离 D（分子与表面/吸附位最近原子间距，Å 或 nm 统一）；
- 关键键长变化（如吸附后 S=O 键伸长量，需与孤立分子对比才有意义）；
- 结构畸变（分子取向、平面性变化、表面弛豫），用文字+数据描述。

来源：博士论文 p85–87（作用距离 D 作为第三维度）；W4399297249 p8（距离 + 吸附类型）。

## 模型与方法交代（报告"计算方法"节）

- 超晶格尺寸与避免相互作用的理由（如 20×20×8.5 Å，博士论文 p82）；
- 简化模型理由（如单个 -OH 代表羟基化表面，博士论文 p81）；
- 初始吸附距离设定与接近方式枚举（博士论文 p83）；
- 二次几何优化流程（先优化基底/分子，再优化吸附体系，博士论文 p84）；
- 收敛标准逐项列出：总能、力、位移、SCF（博士论文 p83；W4399297249 §2.4；W4295832044 §II）。

## 精度规范

- 距离：保留 3–4 位小数（Å 用 2–3 位亦可，全文统一）；
- 能量：2 位小数 eV；电荷：3 位小数 e；
- 表格表头标注单位，单元格只写数值。

## 结构参数的表征写法

给稳定吸附位模型时，按"构型描述 → 关键距离/键长数值 → 与孤立/其他构型的对比 → 结论"组织（来源：博士论文 p86、p89–90）。
