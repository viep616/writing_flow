# 收敛性分析规范

## 报告必须交代的收敛设置（方法节）

- 总能收敛阈值、力收敛阈值、SCF 阈值（pwi 中 etot_conv_thr / forc_conv_thr / conv_thr）；
- 展宽方式与宽度、k 点、截断能（ecutwfc/ecutrho）；
- 色散校正、自旋设置。

来源：博士论文 p83；W4399297249 §2.4；W4295832044 §II（均给出能量/力/位移/SCF 阈值）。

## 收敛性验证（有 convergence_test 时）

1. 固定其他参数，扫描 ecutwfc（如 30/40/50 Ry）与 k 点（如 1×1×2 / 1×1×4 / Gamma）；
2. 计算相邻参数的总能差，判断收敛（如 < 1 meV/atom 量级时说明所选参数足够）；
3. 绘制"总能量 vs 参数"图（折线/柱状）；
4. **未收敛项如实报告**：CSV 中 `no(难收敛)`、`no(SCF慢未完成)` 等状态原文呈现，不剔除；
5. 说明所选参数相对收敛值的能量差，作为"计算设置可信度"依据。

## 数据质量检查（与 input-schema 联动）

- JOB DONE、SCF 收敛、重复文件、缺失文件逐项检查并写入"数据质量"一节；
- 同一体系出现多个 pwo（如 `espresso.pwo` 与 `espresso (1).pwo`）时去重并提示；
- 命名不一致（如 CSV 中 `OH_SO2_top_013`）提示核对。
