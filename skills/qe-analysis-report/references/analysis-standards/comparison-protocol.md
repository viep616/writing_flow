# 比较协议：口径、变量隔离与指标映射

本页是"排序/选择性/对比"类结论的强制检查清单，与 [reasoning.md](reasoning.md) 四步法配套使用。任何排序或对比结论必须同时满足本页原则。

## 核心原则

1. **同口径才排序**：只有同一条件、同一指标、同一单位/符号口径下的数值才能直接比较；跨条件（不同温度/浓度/平衡气/计算参数/电荷方案）只能比趋势，且必须说明。
2. **一次只变一个变量**：可归因的对比必须只改变一个因素（修饰有无、修饰物、配比、位点、分子、手性之一），其余保持相同；跨维度比较必须回到共同子集。
3. **指标-观测量映射声明**：每个 DFT 指标要声明它支撑的结论类型——吸附能回答"谁更易吸附"（热力学），电荷转移回答"谁引起更大电学响应"，作用距离佐证耦合紧密程度，能隙/态密度解释导电性变化。指标排序不一致时，以与实验一致者为主导指标并说明理由（来源：W4399297249 3.3；用户蒸馏页《吸附能、电荷转移量与作用距离的统一计算口径》）。

## 排序前必须对齐的口径

| 口径 | 说明 |
|---|---|
| 响应定义 | ΔR/R 的分子分母与正负方向（(Ra−Rg)/Ra 与 (Rg−R0)/Rg 符号含义相反，不可直接比） |
| 浓度 / 温度 | 同浓度、同温度才可比；报告必须给出 |
| 平衡气/背景 | 空气、Ar、N₂、SF₆ 背景不同，数值不可直接比 |
| 计算参数 | 泛函、截断能、k 点、色散校正、自旋设置一致 |
| 电荷方案 | Mulliken / Hirshfeld 等方案给出的 Q_T 不完全可比 |
| 能隙口径 | HOMO-LUMO（分子轨道）与周期带结构不等价，须注明 |

来源：《灵敏度排序与选择性判别依赖同条件横向比较》；W4295832044 表 I（跨文献对齐表样式）。

## 变量隔离的三条对照基准

- 单载体 + 化学修饰：以**本征体系**为对照（修饰前后差异归因于修饰）。
- 载体 + 纳米颗粒复合：以**同路线合成的无修饰体系**为对照，并核对组分定量。
- 异质结/配比/边缘工程：以**组分单体系 + 配比扫描**为对照。

来源：《载体-修饰-组合三条建模路线及其变量隔离原则》。

## 本项目 94 体系数据场景下的应用

- 同组（chirality, modifier, molecule）内比**位点**（top/bridge/hollow）；
- 同 (molecule, site, chirality) 下比**修饰**（pure/Pt/PtN/PtPd）；
- 同 (modifier, site, chirality) 下比**分子**；
- 手性对比必须在修饰、分子、位点相同时进行。

## 跨文献/跨数据源对比

- 建对齐表（浓度、温度、响应定义、响应时间、选择性、均匀性逐列对齐）后再比较（样式见 W4295832044 表 I）；
- 文献数值或其它软件（如 VASP）数值只能作趋势对照，标注来源与"不同计算方法"限定，不得冒充本数据计算值（见 input-schema.md 的来源约束）。

## 写作动作

- 每次给出排序前，先写一句口径声明："以下排序基于同一（条件/指标/单位），跨条件仅比趋势"；
- 每次归因前，确认只改变了一个变量；
- 指标不一致时，明确写"本报告以 X 指标解释 Y 结论，理由为……"。
