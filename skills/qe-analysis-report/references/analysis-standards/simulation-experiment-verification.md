# 仿真-实验互证（可选模式）

## 启用条件

输入数据包含实验量（响应曲线、灵敏度、恢复时间、稳定性、检测限等）或用户提供实验对照值时启用；否则在报告"数据说明"中写明"未提供实验数据，本节仅做仿真分析"，不得硬凑互证结论。

## 实验侧数据处理流程（按语料归纳）

1. **响应定义**：先声明公式与正负方向。示例：SnO₂-rGO 用 ΔR/R=(Ra−Rg)/Ra×100%（SOF₂ 记负）；TiO₂-NiS 用 S=(Rg−R0)/Rg×100%（正值）。两者符号含义不同，跨文献不可直接比。
2. **温度优化**：扫工作温度定最优工作点，浓度系列在同一温度下测量。
3. **浓度-响应拟合**：线性 / 幂律 / 等温线（Freundlich 等），报告拟合模型与 R²；线性段斜率=灵敏度，饱和段说明适用范围。
4. **检测限**：注明口径——信噪比法（3σ，给出基线噪声统计）或线性回归法。
5. **重复性 / 稳定性 / 干扰**：变异系数 CV、测试天数、干扰气体清单、湿度影响。

来源：《仿真与实验互证先定响应口径再排序对照》发现 1–4（W2801814223、W4295832044、W4399297249、W2355723232）。

## 互证的两种形式

- **排序对照**：仿真指标排序与实验灵敏度排序并列成表，一致才下"最灵敏/选择性最好"结论（样式：thesis 表5.6/5.7 将 E_b、Q_T、D 与实验 S(%)、T(min) 并列；WS₂ 的 DFT 排序与实验灵敏度排序一致）。
- **机理对照**：用 DFT 指标（吸附能 + 电荷转移 + DOS/DCD/能带）解释实验机制（SnO₂-rGO 的 p-n 结/氧负离子机制；TiO₂-NiS 的氧竞争吸附与 F⁻ 相互作用）。

## 指标排序不一致时的处理

示例：TiO₂-NiS 吸附能排序 SO₂ > H₂S > CO ≈ SO₂F₂，电荷转移排序 SO₂F₂ > H₂S > CO ≈ SO₂，与实验灵敏度一致的是电荷转移排序。正确写法：声明用哪个 DFT 指标对应哪种实验观测量，并说明选择理由（来源：W4399297249 3.3；用户蒸馏页《吸附能、电荷转移量与作用距离的统一计算口径》发现 4）。

## 红线

- 无实验数据不得写"与实验一致/基本吻合"；
- 实验与仿真来自不同软件或不同参数时，只作趋势对照并标注；
- 数据质量不一致（如论文摘要与正文数值冲突）时，引用须注明所依据的字段。
