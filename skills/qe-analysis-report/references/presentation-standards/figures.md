# 图表规范

## 推荐图型

- **收敛性**：总能量 vs ecutwfc / k 点（折线或柱状）；
- **吸附能**：同组位点柱状图；批量模式加"修饰 × 分子"热力图；
- **吸附参数四联图**：吸附能 / 化学相互作用能 / vdW 占比 / 电子转移（来源：W4295832044 Fig.5）；
- **相对能量图**：标注最稳定构型（来源：W4295832044 Fig.4）；
- **结构 + 差分电荷密度**成对展示（来源：W4399297249 Fig.7）。

## 图注与题注

- 图注自包含：说明图的内容、条件、单位（"结构参数单位为 Å"）；
- 中文图题 + 英文图题（论文格式，来源：博士论文 图5.1–5.6）；
- 正文先引后述："图 X 显示……"。

## 生成原则（防幻觉）

- 图表由脚本从解析后的数据文件绘制，LLM 不直接画图、不修改数值；
- 缺数据自动跳过对应图型，不硬凑；
- 中文用 SimHei，Unicode 下标转 mathtext（SOF₂ → SOF$_{2}$），避免缺字形。

## 图文结合（锚点插入）

- 正文"先引后述"：在讨论某图的段落后写 `<!-- FIG:<文件名不含扩展名> -->`，渲染时该位置插入图片+程序生成图注；
- 图注必须自包含（内容、条件、单位、数据来源，如"数据表 §3，ΔE 为相对组内最优的代码推导差值"）；
- 无对应论述段落的图不放锚点，宁可缺图不硬凑；无锚点的图由渲染器回退到结果节首/文末并在日志提示。
