# 语言与结构规范

## 语体

- 中文叙述为主，术语保留英文原名（DFT、PBE、DFT-D3、E_ads、SCF），首次出现可加中文全称；
- 避免中英混杂长句（不写"the 吸附能 of 体系 is -1.85 eV"式句子）；
- 数值一律带单位；结论句有数据支撑。

## 摘要规范

结构：背景一句话 → 研究对象与做了什么 → 主要结果（带数值）→ 数据状态/限制。可用编号条目（①②③④）逐项列工作与结果（来源：博士论文摘要 p4）。末尾给关键词。

## 结论规范

编号化（1) 2) 3)…），每条 = 做了什么 + 结果 + 依据；不重复整段正文（来源：博士论文 p93–94；W4399297249 Conclusion）。

## 常用句式（带溯源）

- "从表 X 可以看出，……"（引表后分析）；
- "在吸附能方面……在电荷转移方面……在作用距离方面……综合以上分析，可以得出……"（三维度分析）；
- "结果表明……" / "可以推断……"（推断须给依据，不写成定论）；
- "吸附能力最强/最弱，灵敏度最高/最低"（排序结论）。

## 数值纪律

- 保留有效位数，不四舍五入成整数；
- 未计算的量明确写"未计算/待补充"，不写推测数值；
- 单位换算写在首次使用处（1 Ry = 13.6057 eV 等）。
