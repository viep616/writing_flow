# 吸附能、电荷转移量与作用距离：统一计算口径与联合判读

## 结论

含 DFT 的语料统一用“体系总能差”定义吸附能（E_b=E(复合体)−E(载体)−E(分子)，负值=放热可自发），用电荷布局分析得到分子吸附前后电荷变化作为电荷转移量（符号表示方向），用稳定吸附位的关键原子间距作为作用距离。三指标物理含义不同且排序可能不一致，论文以“与实验响应一致”的指标为主导解释灵敏度。

## 关键发现

### 发现1：吸附能定义在语料内一致

**结论（观察，证据充分）**：学位论文式(5.7) E_b=E_(molecule-SWNT-OH)−E_(SWNT-OH)−E_(molecule)，与 TiO2-NiS 论文 E_ad=E(TiO2-NiS/SO2F2)−E(TiO2-NiS)−E(SO2F2) 完全同构；WS2 论文进一步把吸附能分解为化学相互作用能与 vdW 能（Tkatchenko–Scheffler 色散校正），给出 vdW 占比。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 5.4.1（式5.7）；`D:\papers\_distill_sources\W4399297249.txt` 2.4；`D:\papers\_distill_sources\W4295832044.txt` 2 Methods 与 3.C（图5）。

**推理**：统一的“总能差”口径使吸附能可跨体系比较；WS2 的能量分解则回答“吸附以化学作用还是范德华作用为主”——化学作用强的气体（H2S、SO2）灵敏度更高。

### 发现2：电荷转移量用分子吸附前后电荷变化定义

**结论（观察，证据充分）**：Q_T 定义为气体分子吸附前后电荷变化，符号表示转移方向（如 SO2→SWNT-OH 转移 0.129 e；SOF2 得电子记 −0.026 e）。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 5.4.1（表5.1、5.2）；`D:\papers\_distill_sources\W4295832044.txt` 3.C（图5d）；`D:\papers\_distill_sources\W4399297249.txt` 3.3（电荷转移排序 SO2F2>H2S>CO=SO2）。

**推理**：电荷转移量是连接微观吸附与宏观电阻响应的关键桥梁——论文把“电荷转移量大=电阻变化大=灵敏度高”作为默认推理（如 TiO2-NiS 用电荷转移量解释实验上对 SO2F2 最敏感，尽管其吸附能排序是 SO2>H2S>CO=SO2F2）。

**不确定性**：不同软件/电荷方案（Mulliken、Hirshfeld 等）给出的 Q_T 不完全可比；语料未统一电荷方案，跨文献比较 Q_T 绝对值时应谨慎。

### 发现3：作用距离取稳定吸附位关键原子间距

**结论（观察，证据充分）**：D 为稳定吸附位处关键原子间距（如 SO2-SWNT-OH 0.2440 nm、SOF2-SWNT-OH 0.2865 nm、CF4-SWNT-OH 0.3480 nm），论文用它佐证吸附耦合的紧密程度，但不作为灵敏度排序的主指标。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 表5.2、5.4.2 与5.5.2。

**推理**：D 的排序（SO2F2<SO2<SOF2<CF4）与吸附能、电荷转移排序并不完全一致，说明三指标需联合使用。

### 发现4：吸附能与电荷转移量可给出不同排序

**结论（综合，关键方法学要点）**：TiO2-NiS 体系中吸附能排序 SO2>H2S>CO=SO2F2，而电荷转移排序 SO2F2>H2S>CO=SO2；论文选择电荷转移量作为“实验灵敏度”的解释指标。这提示：吸附能回答“谁更易吸附”，电荷转移回答“谁引起更大电学响应”，两者不能混用。

**证据**：`D:\papers\_distill_sources\W4399297249.txt` 3.3 与 4。

**推理**：如果只报告吸附能，会得出“SO2 最灵敏”的错误结论；正确做法是明确每个 DFT 指标对应的实验观测量（响应幅度、响应时间、选择性方向）。
