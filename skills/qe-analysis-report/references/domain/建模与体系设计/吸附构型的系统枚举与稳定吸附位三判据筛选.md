# 吸附构型的系统枚举与稳定吸附位筛选方法

## 结论

吸附仿真的标准数据前处理流程是：先把气体分子所有可能的“原子—原子”接近姿态逐一建模（姿态数=分子所含原子类型×修饰基团/载体原子类型），统一几何优化后，用“吸附能绝对值最大、电荷转移量最大、作用距离较小”三条判据选出稳定吸附位；后续全部吸附指标与灵敏度推断都在该稳定吸附位上计算，以保证不同气体间的指标可比。

## 关键发现

### 发现1：姿态枚举按原子配对穷举

**结论（观察，证据充分）**：SOF2 与 –OH 的 O、H 两类原子配对产生6种姿态（S-H、O-H、F-H、S-O、O-O、F-O），SO2F2 与 –OH 也是6种，SO2、CF4 各4种；本征 SWNT 则统一让分子各原子接近任意1个 C 原子（稳定位如 SOF2-S-C、SO2F2-O-C、SO2-O-C、CF4-F-C）。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 5.3.3、5.4.1（图5.4）与5.5.1（图5.6）。

**推理**：枚举覆盖所有可能的接触原子对，避免因人为只放一个姿态而漏掉更稳定的吸附构型；这也是后面“吸附能差异”可解释为分子-修饰物化学差异的前提。

### 发现2：二次几何优化与初始距离设定

**结论（观察，证据充分）**：先对载体和气体分子单独几何优化至能量最小，再以 0.15 nm 初始作用距离放入超晶格（20×20×8.5 Å，单分子入晶格以避免分子间、管间相互作用），按每种姿态做二次几何优化。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 5.3.2、5.3.3。

**推理**：先单体优化、后复合优化的两步法，把“吸附导致的弛豫”与“单体本身未收敛”分开，是吸附能差（E_complex−E_carrier−E_molecule）成立的前提。

### 发现3：稳定吸附位的三判据

**结论（观察，证据充分）**：吸附能最大、电荷转移量最多、作用距离较小。示例：SOF2-SWNT-OH 六种姿态中 S-O 的 E_b=−2.27 eV（绝对值最大）、Q_T=−0.026 e（最大）、D=0.2865 nm（较小），被定为稳定吸附位。

**证据**：`D:\papers\_distill_sources\thesis_ch5.txt` 5.4.1（表5.1）与5.4.2（表5.2）。

**推理**：三判据分别对应热力学可行性（E_b<0 自发）、电子响应强度（Q_T）、空间耦合程度（D）；论文用三者交叉验证而不是单指标下结论。

### 发现4：结构工程场景要先筛稳定结构、再筛吸附位

**结论（观察，证据充分）**：WS2 论文先按 S-rich/W-rich 环境比较边缘结构相对能量，选出稳定终止（WS2(1010) 在 S-rich 下 100% S、W-rich 下 50% S；WS2(10-10) 在 S-rich 下 100% S、W-rich 下 75% S 与 50% S），再在所有稳定边缘和表面上做吸附计算并取最大吸附能构型。

**证据**：`D:\papers\_distill_sources\W4295832044.txt` 3.C 理论计算部分（图4、图S11、S12）。

**推理**：在结构工程路线中，“稳定吸附位”的筛选分成两级——先稳定材料结构，后稳定吸附构型；若跳过第一级，吸附指标会混入亚稳结构的贡献。

### 发现5：筛选后的比较才是论文结论的依据

**结论（综合）**：所有灵敏度/选择性结论（如 SO2 最强、CF4 最弱）都基于“各气体在其稳定吸附位上的指标”这一归一化数据集，而非全部姿态的均值。

**推理**：稳定吸附位代表体系热力学最可能状态，与该状态的实验响应对应；但这也意味着仿真结论不覆盖动力学上可能存在的亚稳吸附路径。
